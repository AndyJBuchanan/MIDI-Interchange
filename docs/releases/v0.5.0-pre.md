**MIDI Interchange 0.5.0 (pre-release)**: a MIDI palette for moving MIDI between music apps. Drag in or import MIDI from one or more apps, pick the tracks and ranges you want, and drag them out or export to another.

This release adds **mirror mode**, which keeps the palette in step with a project you're still working on, and brings more of Cubase's own behaviour into the Cubase reader: disabled tracks, linear time-base tracks and track versions now come in the way Cubase plays and exports them. It can open **Cubase 15 and 16** and **Reason 13 and 14** projects directly (other versions aren't supported yet).

MIDI Interchange has no playback, instruments or note editing, and never changes your source files.

## What's new since 0.4.0

**Mirror a project while you work.**

- Choose **File ▸ Open & Mirror MIDI/Project File…** (or **Mirror…** on the toolbar) and pick one Cubase, Reason or DAWproject project, or a MIDI file. The app watches it and re-reads it each time you save in the DAW, so the latest saved state is always on the timeline, ready to export or drag out.
- The window shows clearly that it's mirroring (a cyan frame and a banner with an **Unmirror** button). While mirroring the workspace belongs to the file and is read-only: nothing is dropped, opened or edited.
- A track you haven't touched follows the file's mute and solo at each save; one you mute or solo here keeps your setting. **File ▸ Sync Mutes to File** puts them all back.
- A track's controller display can still be changed while mirroring.
- If a save has no importable tracks, the track list empties and the banner says "No importable tracks in the current save". If a save can't be read, the banner says why and the last good version stays.
- It sees only what the DAW has saved, and a track renamed in the DAW arrives as a new track.

**Cubase reader.**

- **Disabled tracks aren't imported.** A track switched off with Disable Track plays nothing in Cubase and is left out of Cubase's own MIDI export, so it is left out here too, with a note in Source Info. Muted and hidden tracks still come in (hidden ones are noted). A project whose only tracks are disabled says so, rather than failing with a general error.
- **Linear time-base tracks now import.** They used to be skipped. They arrive as ordinary tracks, their positions converted at the project's tempo as saved, which is what Cubase's own export does. They aren't rescaled if the project's tempo is changed later. Source Info notes which tracks were linear.
- **Track versions:** only the active version of a track is imported, as in Cubase's editor and its MIDI export. Parts in other versions are left out.
- A release velocity of 0 is kept as 0 (it came in as 1).
- Checked against Cubase's own MIDI export of the same projects for the disabled, hidden, linear and track-version cases.

**Reason reader.** A song saved three or more times in place could open as an earlier state. The reader now picks the current copy from the song header, so it always reads the last save.

**See controller data.** Pick a controller from the toolbar list and every track that has it draws the curve under its notes (a lane) or over them, as steps or joined lines. A track's header box overrides the choice for that track.

**Simplify controller data (optional, off by default).** Tick it in the export options to thin dense controller streams (mod wheel, expression, pitch bend, aftertouch) to the fewest points that stay within one step of the original. It applies to saving and to dragging out.

**Sources.** The **(i)** beside the track count lists every source in the session with its details and the tracks it feeds, and **Solo all source tracks** solos exactly those tracks.

**Smaller changes.**

- Opening and closing many windows no longer slows the app (and the test suite) down.

## Verification

Automated tests cover the three readers, including note-for-note comparison against Cubase's and Reason's MIDI exports for the checked projects, the new disabled, linear and track-version handling, mirror mode, mute handling, session upgrade and undo. The manual checklist was worked through on macOS with Cubase 16 and Reason projects for each new feature, and the test suite was run on Windows.

Built from commit `34c82cc61596001b9e632bb4f353a48f754ce110`.

## Known limitations

- **Experimental readers.** The project formats aren't published, so the readers were built by studying saved projects. Other Cubase versions are refused with a clear message (Cubase 15 and 16 only); songs saved by Reason 12 and earlier are encrypted, so open them in Reason 13 or later and save again. A DAW update could change a format. If a project won't open, or something looks wrong, a copy of the project helps a lot in a bug report.
- **MIDI only.** Audio, instruments, plug-ins and device automation aren't imported, nor anything a DAW generates at playback: Cubase Pattern Editor parts, the chord track, MIDI inserts and expression-map articulations, and Reason pattern and Player devices. These are listed in Source Info.
- **Cubase linear and track-version cases** were checked on a few projects. Not yet checked: a linear part that spans a tempo change in the project's own tempo, an extended or looped linear part, a linear track in a folder or with a muted part, and Cubase 14.
- **Approximations.** Cubase folders are flattened; Reason's mixer mute and solo are not read; Reason clips' hidden notes and loop structure can't be brought back once written out. Reason's controller data in some projects may not match Reason's own export (CC data that was automation).
- **Mirror mode** has been checked in short sessions with Reason and Cubase; a long (one hour) session has not been tested yet.
- **Reason automation lane:** importing channel-overridden MIDI can add an unwanted Controller #254 lane. The override works; delete the lane in Reason.
- Cursor switching occasionally stops working; the cause is unknown.
- On macOS, Esc cancellation of incoming Finder/Cubase drags remains unresolved. Moving the pointer outside the window restores the timeline view.
- Drag-and-drop support depends on the other app. Cubase drags one clip at a time; Logic can't drag MIDI out. Some apps don't adopt tempo from a drag; open the saved MIDI file instead.
- "Open With" is registered for MIDI files only; drag project files onto the window instead.
- There is no project Save/Open interface; session persistence keeps the current workspace automatically.

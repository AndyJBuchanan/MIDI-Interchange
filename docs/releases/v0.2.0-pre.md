**MIDI Interchange 0.2.0 (pre-release)**: a palette for MIDI on its way between music apps. Drop in bits of MIDI from the apps you're working with, hold them and shape them in one place, then hand exactly what's needed to the next app.

This release is about the awkward parts of that: apps that give up their MIDI only one clip at a time, and parts that go out to another app and come back changed.

It isn't a DAW or an arranger: there's no playback, no instruments and no note editing. This is still a pre-release, so please report anything odd.

## What's new since 0.1.0

**Collect MIDI that comes out one clip at a time.** Some apps drag out a single clip with no position (Cubase drags only one clip at a time), so you now say where each drop goes:

- While you drag in, a cursor and label show the track and bar where it will land, and what the label says is what happens.
- Drop on a track with the **same name** and the clip joins that track at the cursor. Drop anywhere else for a new track.
- Drop several files at once and choose **End to End** (one after another on one track) or **All at Cursor**.

**Round trips: send MIDI out, take it back.**

- A multi-track file dropped on one of its tracks lands back on **all** of them, so MIDI sent to another app and brought back (Staccato.ai, for example) returns to where it was. A clip with exactly the same start and end as one already there replaces it.
- **New song, same parts:** Staccato.ai names tracks "part - song" and changes the song with each generation. Names now match with the song title left out, so "Drums - Staccato Generation" joins "Drums - Industrial EBM Anthem". Clips such as "Lead - Verse" and "Lead - Chorus" are not treated as songs and stay apart.
- An export whose clips all come from one song keeps the song's title, so it can be matched again when it comes back.
- If a drop on a track can't match, the label and status bar say why.

**Reorganise what you're holding.**

- **Option-drag** (Alt-drag on Windows) a clip to move it in time or onto another track; drag below the last track for a new one. **Option-⌘-drag** (Alt+Ctrl) copies it.
- Right-click a clip to duplicate it, butt it against the previous clip, move it to another track or delete it. Clips may overlap; the overlap is tinted red and both are exported.
- Right-click a track to merge it into another, solo it for export, move it up or down, or save just that track.
- **File ▸ New** (⌘N) clears the workspace; Undo brings it back.

**Hand on just the tracks each app needs.**

- Each range has a checkbox in every track lane, so each range can send a different set of tracks. Right-click a range for Include All, Exclude All and Reset to Track Toggles.
- Option-click (Alt-click) a track's checkbox to set it in every range at once.

**Export names and defaults.**

- An export is named after its track, or after its ranges ("Verse + Chorus"). Separate files dragged out are named after each range ("Verse.mid"; a repeat gets " (2)").
- The default export is now **Ranges · rebase & concatenate**.

**Smaller things:** gentler lane height on Option + mouse wheel (Alt on Windows), track headers no longer draw over the "TRACKS" band when scrolled, and many fixes from hand testing.

## Known limitations

- **Drag and drop with other apps depends on what each app supports.** On macOS it has been tried with Cubase 16, Reason 14, Staccato.ai, Scaler 3, RapidComposer 6 and Logic Pro, and works as far as each app allows: Cubase drags out one clip at a time, Logic can't drag MIDI out, and Reason splits a track that mixes MIDI channels into one track per channel. Dragging into Cubase and Reason doesn't bring the tempo along; opening the saved file does. Windows drag and drop hasn't been checked with DAWs yet.
- On Windows, opening several files at once from Explorer opens several windows. Drag them onto one window instead.
- Workspaces can't be saved or reopened yet; keeping your session between runs is planned.
- No app icon yet.
